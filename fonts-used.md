# Fonts Used on the Holykey Website

> Generated by scanning all HTML, CSS, and JS files in `/public`.

## Google Fonts (loaded via `fonts.googleapis.com`)

| Font | Type | Used In |
|------|------|---------|
| **Roboto** | Sans-serif (primary UI font) | Every HTML page — loaded in weights: 100, 300, 400, 500, 700 |
| **Material Symbols Outlined** | Icon font | Every HTML page (except `remote-desktop.html`) |

- Google Fonts URL loaded on nearly all pages:
  ```
  https://fonts.googleapis.com/css2?family=Material+Symbols+Outlined:opsz,wght,FILL,GRAD@20..48,100..700,0..1,-50..200&family=Roboto:wght@100;300;400;700&display=swap
  ```
- `theater-details.html` additionally loads Roboto weight **500**.
- `remote-desktop.html` loads **Roboto only** (weights 300, 400, 500).

## System / Local Fonts (with fallback stacks)

## Summary

1. **Roboto** — The primary typeface for all UI text (body, headers, buttons, labels).
2. **Material Symbols Outlined** — The icon font used everywhere for UI icons.
3. **SFMono-Regular / ui-monospace / Courier New** — Monospace fonts for terminal, code, and chat.
4. **Generic fallbacks** — `sans-serif`, `monospace`, `Consolas`, `Menlo`, `Liberation Mono`.

## Self-Hosted Fonts (local files at project root)

Roboto has been downloaded and placed in `/fonts/` at the project root, along with a local CSS file.

| File | Description |
|------|-------------|
| `fonts/Roboto-latin.woff2` | Latin subset — covers all weights (100–900) as a variable font |
| `fonts/Roboto-latin-ext.woff2` | Latin-ext subset — extended Latin characters |
| `fonts/fonts.css` | `@font-face` declarations referencing the local woff2 files |

### To use locally instead of Google Fonts:
Replace the Google Fonts `<link>` in your HTML with:
```html
<link rel="stylesheet" href="/fonts/fonts.css">
```

### Locally self-hosted file sizes:
- `Roboto-latin.woff2` — **43 KB**
- `Roboto-latin-ext.woff2` — **29 KB**
